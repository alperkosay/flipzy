# Changelog

## 0.1.0

- First release: `FlipBook` component, `useFlipBook` hook, single and double page layouts, drag, click and keyboard flipping, SSR and Next.js App Router support.
- Hover peek: page corners lift when the mouse is over them (`hoverPeek`).
- Optional theme `flipzy/styles.css`: light, dark and flat themes, page stack edges, book shadow and control styles.
- Class names (`flipzy__book`, `flipzy__page--left`, …), `data-spread` and `--flipzy-progress` for custom styling.
